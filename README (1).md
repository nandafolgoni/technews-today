# TechNews Today 📰

## 📌 Sobre o projeto

O **TechNews Today** é uma página web de notícias sobre tecnologia, desenvolvida com **HTML5** e **CSS3**. O projeto simula um portal moderno de tecnologia, apresentando notícias, conteúdo em vídeo e um formulário para inscrição em uma newsletter.

O objetivo do projeto é praticar a criação de uma página HTML com estrutura semântica, formulários, incorporação de vídeos e estilização utilizando CSS.

## 🎯 Objetivos

- Criar uma página web utilizando HTML semântico.
- Organizar o conteúdo em cabeçalho, conteúdo principal e rodapé.
- Utilizar elementos como `header`, `main`, `article`, `section`, `footer`, `form` e `address`.
- Criar um formulário de inscrição para newsletter.
- Incorporar um vídeo do YouTube utilizando `iframe`.
- Aplicar estilos modernos utilizando CSS3.
- Trabalhar com responsividade e layout utilizando CSS Grid.

## 🛠️ Tecnologias utilizadas

- **HTML5** — estrutura e organização da página.
- **CSS3** — estilização, cores, gradientes, efeitos e responsividade.
- **YouTube** — incorporação de conteúdo em vídeo.

## 📁 Estrutura do projeto

```text
projeto/
├── index.html
├── 10a_desafio.css
```

### `index.html`

Arquivo principal da página. Contém toda a estrutura do portal, incluindo:

- Cabeçalho com o nome do site;
- Notícia em destaque;
- Data da publicação;
- Área de vídeo;
- Formulário de newsletter;
- Rodapé com informações de contato.

### `10a_desafio.css`

Arquivo responsável pela aparência da página. Nele são definidos:

- Cores e fontes;
- Gradientes;
- Espaçamentos;
- Cards;
- Botões;
- Efeitos de hover;
- Layout com CSS Grid;
- Responsividade para diferentes tamanhos de tela.

## 💻 Funcionalidades

### 📰 Notícia em destaque

A página apresenta uma notícia sobre inteligência artificial e desenvolvimento de software. O elemento `details` permite que o usuário clique em **"Leia mais"** para visualizar uma informação adicional.

### 📺 Vídeo

O projeto possui uma seção **"Tech em Vídeo"**, utilizando um `iframe` para incorporar um vídeo do YouTube diretamente na página.

### 📧 Newsletter

O formulário permite que o usuário informe:

- E-mail;
- Área de interesse;
- Aceite dos termos.

O formulário utiliza campos obrigatórios para garantir o preenchimento das informações necessárias.

### 📱 Responsividade

O CSS utiliza uma `media query` para adaptar o layout em telas maiores. O conteúdo passa a utilizar duas colunas a partir de **768px** de largura.

## 🚀 Como executar

1. Baixe ou clone o projeto.
2. Mantenha os arquivos `index.html` e `10a_desafio.css` na mesma pasta.
3. Abra o arquivo `index.html` em um navegador.
4. A página será carregada e poderá ser visualizada normalmente.
